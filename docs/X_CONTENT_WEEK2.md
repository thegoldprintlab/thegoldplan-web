## DAY 9 — Mekanik kill switch (paling "save"-able)

How my daily loss limit actually works:

1. Set the limit in $ per account, not %
2. At 50% — warning. Size down.
3. At 80% — walk away. No new trades.
4. At 100% — platform closed. Done for the day.

Prop firms fail you at the daily drawdown. This makes sure I never find out what that feels like.

## DAY 12 — Q&A post (minta engagement, bukan link)

Genuine question for gold traders:
